# Changelog

## Unreleased

- Color themes: `theme` selects a preset for the dark and light cards (GitHub, Dracula, Tokyo Night, Nord, Monokai, Solarized), and `colors` overrides single colors.

## 0.1.0

First version.

- Terminal-style SVG profile cards, light and dark, from a local ASCII file and a JSON config.
- GitHub Primer colors, embedded Fira Code subset, ANSI palette.
- Options: `palette`, `prompt`, `leaders`, `command`.
- Field-level validation errors and clear CLI messages.
- `npm run card -- <profile.json> <output-directory>`.
